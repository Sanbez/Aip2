## Как стать администратором

### Вариант 1: Через браузер (для разработки/тестирования)

1. Откройте консоль браузера (F12)
2. Выполните следующие команды:
   ```javascript
   // Установить ваш ID пользователя
   localStorage.setItem("userId", "demo_admin_1")
   localStorage.setItem("userName", "Ваше Имя")

   // Обновить страницу
   location.reload()
   ```

3. Теперь перейдите на `/admin` - у вас будет доступ к админ-панели

### Вариант 2: Добавление через код

Откройте файл `lib/admin-context.tsx` и добавьте ваш ID в массив `DEFAULT_ADMINS`:

```typescript
const DEFAULT_ADMINS = ["demo_admin_1", "demo_admin_2", "ваш_user_id"]
```

## Доступ к админ-панели

### URL: `/admin`

После входа как администратор перейдите по адресу:
- Локально: `http://localhost:3000/admin`
- На продакшене: `https://ваш-домен.com/admin`

### Защита
- Только пользователи с ID в списке администраторов могут получить доступ
- При попытке доступа без прав вы будете перенаправлены на главную страницу
- Отобразится уведомление: "У вас нет прав администратора"

## Обзор функций

### 📊 Статистика (верхние карточки)

| Показатель | Описание |
|-----------|----------|
| **На модерации** | Количество мероприятий, ожидающих проверки |
| **Опубликовано** | Количество одобренных и активных мероприятий |
| **Отклонено** | Количество отклоненных мероприятий |
| **В архиве** | Количество архивированных прошедших мероприятий |

### 🔍 Поиск и фильтрация

- **Поиск**: По названию, описанию или организатору
- **Сортировка**:
  - По дате создания (новые первыми)
  - По дате события
  - По названию (алфавит)

### 📑 Вкладки

1. **На модерации** - новые заявки на публикацию
2. **Опубликовано** - активные мероприятия на сайте
3. **Отклонено** - отклоненные заявки с причинами
4. **Архив** - прошедшие мероприятия

## Модерация мероприятий

### Одобрение мероприятия

1. Перейдите на вкладку **"На модерации"**
2. Просмотрите карточку мероприятия
3. Нажмите кнопку **"Одобрить"** (зеленая)
4. В диалоговом окне:
   - ✅ Выберите пины (опционально):
     - 🔥 **Промо** - рекламное мероприятие
     - ⭐ **Избранное** - выделенное мероприятие
     - 💎 **Эксклюзив** - эксклюзивное предложение
     - ✨ **Новое** - новое мероприятие
   - ✅ Добавьте комментарий (опционально)
5. Нажмите **"Одобрить"**

**Результат**: Мероприятие станет видимым на главной странице сайта

### Отклонение мероприятия

1. Перейдите на вкладку **"На модерации"**
2. Нажмите кнопку **"Отклонить"** (красная)
3. В диалоговом окне:
   - ⚠️ **Обязательно** укажите причину отклонения
   - Примеры причин:
     - "Недостаточно информации о мероприятии"
     - "Неподходящая категория"
     - "Некорректная дата или время"
     - "Нарушение правил платформы"
4. Нажмите **"Отклонить"**

**Результат**: Мероприятие не будет опубликовано, организатор увидит причину

### Редактирование мероприятия

1. Найдите нужное мероприятие
2. Нажмите кнопку **✏️ (Edit)**
3. Отредактируйте поля:
   - Название
   - Описание
   - Категория
   - Дата и время
   - Локация и адрес
   - Цена
   - Количество участников
   - Организатор
4. Нажмите **"Сохранить изменения"**

### Удаление мероприятия

1. Найдите нужное мероприятие
2. Нажмите кнопку **🗑️ (Delete)**
3. Подтвердите удаление

⚠️ **Внимание**: Удаление необратимо!

### Просмотр мероприятия

Нажмите кнопку **👁️ (Eye)** чтобы открыть страницу мероприятия как обычный пользователь

## Пины и метки

### Что такое пины?

Пины - это специальные метки, которые выделяют мероприятие среди других и привлекают к нему внимание пользователей.

### Доступные пины

| Пин | Значок | Использование | Где отображается |
|-----|--------|---------------|------------------|
| **Промо** | 🔥 | Рекламные/спонсорские мероприятия | Главная страница (секция "Горячие предложения"), фильтр "Промо" |
| **Избранное** | ⭐ | Рекомендованные редакцией | Карточки мероприятий |
| **Эксклюзив** | 💎 | Уникальные предложения | Карточки мероприятий |
| **Новое** | ✨ | Недавно добавленные | Карточки мероприятий |

### Как добавить пины

Пины добавляются при одобрении мероприятия:

1. Нажмите **"Одобрить"** на мероприятии
2. В диалоге отметьте нужные пины галочками
3. Подтвердите одобрение

### Стратегия использования пинов

**🔥 Промо:**
- Платные/спонсорские мероприятия
- Акционные предложения
- Ограниченное время (не более 10-15% всех мероприятий)

**⭐ Избранное:**
- Высококачественные мероприятия
- Проверенные организаторы
- Интересные форматы

**💎 Эксклюзив:**
- Уникальные события
- Впервые в городе
- Ограниченное количество мест

**✨ Новое:**
- Добавлено в последние 3-7 дней
- Помогает пользователям находить свежие предложения

## Массовые действия

### Как использовать

1. Отметьте несколько мероприятий галочками
2. Внизу появится панель с выбранным количеством
3. Выберите действие:
   - **Одобрить все** (только для "На модерации")
   - **Отклонить все** (только для "На модерации")
   - **Удалить все** (для всех вкладок)

### Рекомендации

- ✅ Используйте для одобрения похожих мероприятий от проверенных организаторов
- ✅ Удобно для очистки старых отклоненных заявок
- ⚠️ Будьте осторожны с массовым удалением!

## Советы и лучшие практики

### ✅ Что делать

1. **Проверяйте качество**
   - Полнота информации
   - Корректность дат и времени
   - Адекватность цены
   - Соответствие категории

2. **Оставляйте комментарии**
   - При отклонении всегда указывайте причину
   - При одобрении можно добавить пожелания

3. **Используйте пины разумно**
   - Не помечайте все как "Промо"
   - Избранное - только качественные события
   - Новое - действительно свежие мероприятия

4. **Регулярно проверяйте очередь**
   - Заявки на модерацию должны обрабатываться в течение 24 часов
   - Быстрое одобрение повышает лояльность организаторов

### ❌ Чего избегать

1. **Не удаляйте без причины**
   - Лучше отклонить с объяснением
   - Удаление - только для спама/нарушений

2. **Не злоупотребляйте пинами**
   - Если все "Промо", то ничто не "Промо"
   - Избирательность привлекает внимание

3. **Не игнорируйте отклоненные**
   - Периодически очищайте старые отклоненные заявки
   - Архивируйте прошедшие мероприятия

## Часто задаваемые вопросы (FAQ)

### Q: Как добавить нового администратора?

**A:** Откройте `lib/admin-context.tsx` и добавьте его userId в массив `DEFAULT_ADMINS`, либо используйте функцию `addAdmin()` в коде.

### Q: Можно ли отменить одобрение?

**A:** Да, вы можете удалить мероприятие или отредактировать его. Также можно вручную изменить статус в localStorage (для разработки).

### Q: Что происходит с прошедшими мероприятиями?

**A:** Они автоматически архивируются. Вы можете увидеть их на вкладке "Архив".

### Q: Можно ли редактировать пины после одобрения?

**A:** Да, используйте кнопку "Редактировать" и измените нужные поля. Затем нужно будет заново одобрить с новыми пинами.

### Q: Сколько хранится история модерации?

**A:** По умолчанию 30 дней. Можно настроить через функцию `clearOldLogs()`.

## Техническая информация

### Хранение данных

- Все данные хранятся в **localStorage** браузера
- Ключи:
  - `event-marketplace-events` - события
  - `event-marketplace-admins` - список администраторов
  - `event-marketplace-moderation-logs` - логи модерации

### Статусы мероприятий

```typescript
type EventStatus = "pending" | "approved" | "rejected" | "archived"
```

- `pending` - ожидает модерации
- `approved` - одобрено, видно пользователям
- `rejected` - отклонено
- `archived` - архивировано (прошедшее)

### Структура пинов

```typescript
interface EventPins {
  isPromo?: boolean      // Промо
  isFeatured?: boolean   // Избранное
  isExclusive?: boolean  // Эксклюзив
  isNew?: boolean        // Новое
}
```
